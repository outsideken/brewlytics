The Simpsons: A d3.js Force-Directed Network Graph

Built with d3.js v7.9.0 · layout: d3-force · force-directed graph example

Node size = PageRank, ignoring link direction; colour = Louvain community, named after its best-connected member; arrows show one-way relationships; link labels show for the focused node, or everywhere once zoomed in. Drag a node to move it · scroll or pinch to zoom · hover a node, or click to pin it · click a category to hide or show it.
